## Overview

Server-only (`server_only "yes"`) connection queue. Tracks total/session join counts, holds a temporary whitelist and whitelist-group override, and publishes `GlobalState["MaxPlayers"]` from the `sv_maxclients` convar.

---

## Dependencies

- `pulsar_core` — framework core
- `pulsar_pwnzor` — anti-cheat check loaded alongside every resource
